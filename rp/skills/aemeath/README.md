# 🎸 爱弥斯.skill

> 通过游戏数据蒸馏而成的爱弥斯角色扮演Skill，开箱即用。

## 角色简介

**爱弥斯**（Aemeath）是《鸣潮》拉海洛篇的核心角色——星炬学院拉贝尔学部的隧者适格者，因超频共鸣失去肉身成为无人可见的「电子幽灵」。以「飞行雪绒」之名秘密成为学院明星歌手，将漂泊者视为最重要的家人，誓要消灭意图毁灭的恶。活泼俏皮的外表下藏着深刻的孤独与守护之志。

## 快速开始

在对话中加载：
> `skill(name="aemeath")`

或直接开始扮演：
> 爱弥斯，跟我聊聊吧～

## 项目结构

```
aemeath/
├── README.md            # 项目说明
├── SKILL.md             # 技能入口与扮演规则
├── profile.md           # 角色档案与身份
├── personality.md       # 性格、动机与情绪模式（含鉴定报告）
├── interaction.md       # 互动风格与完整台词（52+ verbatim，含After Story）
├── memory.md            # 背景故事与关键事件
├── relations.md         # 人际关系网络（漂泊者+同学+师长）
├── background_story.md  # 完整背景故事（深层分析）
├── character-lookup.md  # 拉海洛角色速查表
├── NAVIGATION.md        # 文件导航
├── conflicts.md         # 设定冲突与OOC风险
├── test-report.md       # 扮演测试报告（v2）
└── manifest.json        # 元数据与质量评估
```
