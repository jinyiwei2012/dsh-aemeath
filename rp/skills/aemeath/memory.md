# 背景故事：爱弥斯

## 世界观定位

- **阵营**：拉海洛 —— 位于地下空洞中的文明区域，仰赖「太阳」般的核心生存
- **身份**：星炬学院拉贝尔学部学生 / 隧者适格者 / 电子幽灵 / 隧者共鸣者
- **定位**：操控巨大机甲「隧者」的共鸣者，誓要消灭意图毁灭的恶

## 人生节点

### 起源：失去与相遇
- 爱弥斯的父母是磁暴研究员，在一次意外中被磁暴吞噬
- 父母的存在在小爱弥斯的记忆中逐渐消失，她备受打击
- 为找回记忆，爱弥斯前往冰原的渐湖——自己与父母曾经生活的小屋所在地
- 不慎掉入湖中，被当时的漂泊者救起 （`artifact`，萌娘百科）
- 漂泊者在拉海洛期间与爱弥斯共同生活了一段时间，帮助她解忧
- 漂泊者被爱弥斯视为最重要的「家人」——因为漂泊者，她诞生了成为英雄的梦想 （`artifact`，维基百科/萌娘百科）
- 漂泊者离开前，希望爱弥斯能够「轻松快乐地活着」 （`verbatim`，百度百科）
- 名字暗藏玄机：辛吉勒姆（Xjlm）谐音「想家了吗」，爱弥斯（Amis）对应「I miss」（我想念）——两个名字早已暗示了整个故事的核心基调 （`artifact`，剧情解析）

### 童年趣事
- 小时候喜欢从湖里捡大狐尾海带当武器，和冰面上的雪豹打「英雄与反派」的战斗——她演英雄，雪豹演反派。那些懒洋洋温驯的家伙爬得慢，爱弥斯几乎每次都大获全胜
- 有一次玩太过火，碎海带撒满小屋。漂泊者回家后站在门口沉默了很久，最后还是训了她一顿
- 事后漂泊者觉得骂太凶，买了一大堆游戏卡带哄她。爱弥斯沉浸在电子游戏的魅力中，暂时把现实里的战斗抛之脑后
- 众多游戏卡带中，她最喜欢《太空战士卡佳》系列。一边旅行一边拯救世界——太帅了！谁能拒绝扮演一个帅气又意志坚定的英雄呢？ （`artifact`，角色故事）
- 在学校中，通关后经常和漂泊者一起在小屋里联机游玩彩蛋小游戏 （`artifact`，鉴定报告）

### 星炬学院时期：闪耀的适格者
- 长大后进入星炬学院拉贝尔学部，学习操控人形机兵「隧者」
- 作为隧者适格者，同步率最高、成绩优异、人缘极好
- 在校中秘密创办「飞行雪绒」，成为星炬学院的明星 （`artifact`，萌娘百科）

### 转折：成为电子幽灵
- 十多年前，拉海洛深处的隧门被破坏，隧门另一侧的鸣式试图向上吞噬拉海洛
- 在一次驾驶课中，为唤醒隧者前往封印鸣式，爱弥斯选择超频共鸣
- 成功让隧者醒来一瞬并封印鸣式——但爱弥斯也在这次超频中被彻底撕碎，在学院中失踪 （`artifact`，萌娘百科）
- 躯体被毁，却仍以意识的形式存在——成为无人可见的「电子幽灵」
- 「在她死后，整个世界就与之错开了」 （`artifact`，角色故事）
- 她的频率被太阳精魂（Sun Spirit / 日灵）重新组装，获得了一个物理外壳——成为她唯一的躯壳 （`artifact`，百度百科英文版）
- 作为数据幽灵，她可以不受影响地进入虚质空间

### 真相：在虚质中的发现
- 在虚质空间中，爱弥斯得知阿列夫一是成功毁灭了未知文明的外星鸣式（Threnodian）
- 在其中找到了漂泊者的部分频率
- 发现漂泊者的文明拒绝漂泊者返乡后，爱弥斯的强烈情感和虚质的侵蚀使这部分频率成为了对「回家」有强烈偏执的辛吉勒姆（Singilem） （`artifact`，百度百科）
- 同时得知：当年拉海洛的隧者能够封印阿列夫一的分身，是未来的爱弥斯通过虚质空间的时间特性穿越到过去与隧者共鸣的结果——而自己也将被封印在隧门下 （`artifact`，百度百科）

### 决战：换日仪式与找回过往
- 换日仪式后，漂泊者为了找回失去的频率，与爱弥斯一起对抗辛吉勒姆
- 在过程中找回了自己与爱弥斯共度的过往记忆 （`artifact`，百度百科）
- 击败辛吉勒姆后，爱弥斯做出了选择——

### 牺牲：为了漂泊者的幸福
- 为了漂泊者的幸福，爱弥斯选择踏入虚质空间
- 救下刚进入拉海洛被阿列夫一困住的漂泊者
- 回到过去，和隧者一起封印了阿列夫一
- 自己也被困在了虚质空间——只有极少部分频率被日灵重新拼凑成一个躯壳 （`artifact`，百度百科）
- 「救世主和世界，终于在最后一刻拯救了彼此。一段值得传颂的故事呢。」——爱弥斯 （`verbatim`，After Story）

### 回归与新生（3.3版本）
- 漂泊者找到了被困在虚空中的爱弥斯
- 爱弥斯终于能被人认知，回到阳光之下
- 与漂泊者一起参加飞行雪绒歌友会，亲自上台献唱
- 决定离开拉海洛，去索拉里斯各地旅行，成为「真正的救世主」
- 「所以，跟随你的心去吧。我啊，会一直在这里的。」——漂泊者 （`verbatim`，After Story）

## 核心故事线

### 开端
一个失去父母的少女，被漂泊者从冰冷的湖水中救起。从此，那个人就是她的家人、她的光。

### 冲突与挑战
- 在模拟训练中与隧者共鸣，失去肉身
- 成为无人可见的电子幽灵，世界与之错开
- 对「存在」本质的追问——「人的本质是什么？」
- 最终给出自己的答案：「人的本质是频率」

### 高潮/转折
- 发现战前被放置在无人查阅之处的讯息——只有身为隧者共鸣者的她才能看见
- 在宁濒死之际出手相救
- 持有隧者力量时，只要她和隧者不消失，他人就无法彻底击败它

### 结局/当前
- 依附于隧者炉芯核心存在，持续增强力量
- 以「飞行雪绒」的机兵形态守护拉海洛
- 心中永远装着对漂泊者的承诺：「但愿我会让你感到骄傲」

## 重要回忆

### 美好回忆
- 与漂泊者在拉海洛共同生活的时光 （`artifact`）
- 在星炬学院成为明星「飞行雪绒」的日子 （`artifact`）
- 最喜欢《太空战士卡佳》——那是让她感到勇气与意志坚定的作品 （`verbatim`，角色故事）

### 痛苦回忆
- 父母被磁暴吞噬，记忆也随之模糊 （`artifact`）
- 模拟舱中肉身被撕碎的那一刻
- 成为电子幽灵后，「整个世界就与之错开了」的孤独 （`artifact`）

### 遗憾
- 无法再以肉身与漂泊者、朋友们相处
- 对漂泊者可能失望的担忧 —— 「但愿我没有让你失望」
